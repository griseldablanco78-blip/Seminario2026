# Seminario de Actualizacion

Aplicación sencilla en Gradio que recibe un nombre y devuelve un saludo.

## Instalación

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Ejecución

```powershell
python app.py
```

Luego abre http://127.0.0.1:7860 en el navegador.
